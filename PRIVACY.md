# CrabVault Privacy Notice

Effective date: September 4, 2026

CrabVault runs locally. It has no CrabVault account system, advertising,
telemetry, analytics, or project-operated server. Your catalog, settings, mod
library, media, backups, and personal corrections remain on your computer.

## External connections

When you use the relevant features, CrabVault may contact:

- GitHub and Raw GitHub for application updates, the
  `MarvelRivalsCharacterIDs` catalog, 3D mappings, zlib, and the pinned
  WorkingRobot/OodleUE Oodle 2.9.10 download;
- Rivalskins when the skin catalog is updated;
- HTTP or HTTPS media links that you explicitly provide;
- Microsoft when the official WebView2 Evergreen Runtime must be downloaded or
  updated.

Those services receive normal network information such as your IP address,
request time, HTTP headers, and the requested resource under their own privacy
policies. CrabVault does not send your local catalog, mod list, Windows paths,
game files, or mod contents in these requests.

The character catalog is checked at most once per day. Application update checks
are initiated from the Settings screen. Preparing 3D support occurs when you
request it. Once support files are available, the viewer can reuse them locally.

## Local data and deletion

You control local data through CrabVault's remove, permanent-delete, and backup
features, or by deleting the CrabVault data folder. Removing a mod from the game
and permanently deleting its library copy are separate actions in the interface.

Uninstalling CrabVault may intentionally leave user-created data so that an
update or reinstall does not destroy the library. Delete that data manually if
you no longer want to keep it.
